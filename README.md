# Who Killed Taste?

An interactive data story examining how recommendation systems influence what
people encounter, consume, and may choose next.

The project combines editorial scrollytelling with interactive demonstrations
and published research on TikTok, Spotify, and X. The simulated feed responds
to reader behavior, while reported study results remain visually and
editorially distinct from the demonstration.

## Built with

- React and TypeScript
- D3.js
- Three.js
- p5.js
- Vite and vinext

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Editorial note

The interactive feed is an illustrative recommendation model, not a recreation
of any platform's proprietary system. Statistical findings are attributed to
their original studies within the story.
